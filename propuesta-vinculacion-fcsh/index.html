    ¿POR QUÉ POR NOMBRE Y NO POR CÓDIGO?

    Porque el mismo código cambia de proyecto entre periodos:

    24-25P9SOC05 = Kitu Kara tejido comunitario
    →
    26-26P9SOC05 = Barrios DMQ

    Pasa también con P2SOC02, P2SOC03, P2SOC04 y P9SOC04. El nombre del proyecto es lo único estable; por eso va primero, y cada código va con su periodo. Tampoco se usa el nombre del docente, porque cambia.

    03 · Regla de nombres

    Un nombre que se entiende sin abrir el archivo

    Para los archivos nuevos: cuatro partes, siempre en el mismo orden.

    BarriosDMQProyecto_ InformeTrimestralDocumento_ 2026-jul-sepPeriodo_ v1Versión.pdf

    Antes y después (archivos reales)

    pofa Myriam PnaherreraFORMATO_INFORME_AVANCE_TRIMESTRAL_FINAL_periodo_26-26 julio seotiuembre-signed-signed.pdf
    →
    BarriosDMQ_InformeTrimestral_2026-jul-sep_v1_firmado.pdf
    PROF CRISTIAN ARTEAGA_INFORME_AVANCE_TRIMESTRAL_FINAL_julio septiembre (1)-signed-signed-signed-signed.pdf
    →
    SeguridadDigital_InformeTrimestral_2026-jul-sep_v1_firmado.pdf
    CRONOGRMA 2024-2025.pdf
    →
    ColeccionFilosofica_Cronograma_24-25_v1.pdf
    «_firmado» solo al finalSolo la versión final firmada lo lleva. Nada de «-signed-signed-signed».
    El código va dentroEl código del periodo se escribe dentro del documento y en la carpeta, no se adivina.
    Una carpeta por proyectoNunca se reutiliza una carpeta para dos proyectos que tuvieron el mismo código.
